## P0：冻结边界与证据样本

1. 以本目录范围建议形成首版受控taxonomy：海域、鱼种、渔法、业务活动、政策/资源/经营/技术类型。读者优先中国远洋经营运营，其次贸易加工；不采集船员个人数据和实时船位。
2. 用10—15个明确登记的入口试点，先人工抽样30—50件，再扩大到不少于100件用于评分校准；样本量是计划目标，未完成。必含官方单源低热度政策、中文修订、日文资源预报、英文CMM、多页表格、旧文未来生效、附件换版、撤回与跨语种复述。

国内基线样本至少同时核对新修订渔业法（2026-05-01施行）、远洋规定2025修订和外籍船员2024正式通知；不能把2023征求意见稿、2020原版或旧法版本当现行完整基线。各条款实际适用与后续配套更新进入审核，不能从实施答问生成法律全文。
3. 逐源确认权利与采集条件；未知不得默认全文。政策有效性与表格数据由有行业背景人员抽核，不让模型给自己作最终验收。若暂时没有审核人，允许做内部候选库，政策确定性对外输出保持关闭；不会因此阻断研究规划。
4. 记录来源、原件hash、页码、解析结果、人工基准；评分重要性与事实正确性分别标注。首版门槛由样本结果决定，不在文档凭感觉修改60/65/76。

## P2：Easel本机桥接、人工闭环

先导出一个经审核的Markdown+JSON包，手动上传Easel验证引用与创作，再实现独立拉取桥接器及本地台账。每个样本从原文→证据→素材包→Easel草稿→人工核查逐步验收；无自动发布需求在此阶段重新创建调度。现有08:30早报及其会话/配置保持原样。

新增桥接器不放进Easel内建RSS脚本硬编码全局源；可先放本中心 `tools/easel-bridge/` 或独立目录，版本合同独立，确定真正接口后才选位置。既有 `/api/upload` 仅本地使用，附件超限拆包或提供许可内摘要，不伪造附件ID。direct_api模式下仅可消费文本，若需工具工作流必须先验证该模式实际支持。

## P3：用户批准后的部署试点

本次不进入此阶段。先取得具体主机/域名和资源只读信息，设计自有品牌、条款及DNS/证书变更清单供用户批准，再上线。未确认2核4GB能否承载实际库/解析负载；先本地/隔离环境重放样本并量化性能，再承诺规格。

需要用户后续批准的是真实域名、条款、付费额度及对外发布等具体动作，不是“请先替我们决定捕捞区”。前期自主规划和文档可继续。

## 关键行为验收与失败条件

| 用例 | 通过条件 | 失败处置 |
|---|---|---|
| 官方政策没有转载、分数低 | 仍进入政策待审；新闻精选与政策档案分开 | 暂停政策出包，修正路由，不全站降低评分阈值 |
| 当前仍适用的旧文超出首次约12个月导入，或配置publishedAfter且日期不明 | 政策目录基线与观测在新闻时间准入之前保留，未知日期可待审；不改全站新闻准入 | 暂停政策完整性宣称，核查source-specific采集，不靠模型补造日期 |
| 2020原版与后续修订/成员实施 | 保留原件、规范编号、关系与生效依据 | 只给历史索引，不声明现行完整法规 |
| A→B→A；网页不变附件变 | 三次观察可见、二次及回退有差异，附件hash独立 | 停止自动确认“未变”，保留原件人工核验 |
| 日文/英文同措施、同标题不同年份 | 前者有证据才归并，后者不误合并 | 进入人工关联队列 |
| 表内合计与分项不符、吨/千吨 | 报冲突且不发布计算性履约结论 | 标记source_conflict，不自动修正官方值 |
| 未来生效/异议/豁免/期限不明 | 每项有锚点、精度、未知和人工状态 | 阻止确定性影响结论 |
| 摘要许可却请求全文/原件 | 明确拒绝，日志无敏感信息 | 撤销导出并追踪下游稿件 |
| 游标过期/断点/重复/withdraw | 无丢失、幂等、重建snapshot明确、撤回进入台账 | 暂停桥接、保留检查点，人工处理已有稿 |
| 密钥误配/后台直出/对象桶公开 | 权限隔离测试失败即不部署 | 保持网络未暴露；若已暴露按实际事件响应 |
| 恢复演练 | 数据库+证据原件+许可/解析版本可恢复，hash一致；撤回和预算对账、更新epoch后桥接重同步 | 素材出口保持关闭，不承诺长期档案可用；不得复活已撤回素材或重置已消费费用 |

代码实施后按AGENTS运行类型检查、隔离测试库测试、前端构建/测试，部署后再运行smoke。禁止在当前只读研究阶段为了“完成清单”启动未知仓库代码。本次文档仅检查链接路径、JSON例子、diff与无敏感内容。

## 回滚与交付定义

配置和模块以独立提交实现，先可关闭导出/提醒/付费与采集开关；关闭功能不删除已存证据。迁移优先向前兼容，真正破坏性回退另写恢复步骤并经授权。桥接故障停止拉取/生成，保留游标台账；已发布内容依处置流程更正，不伪造全平台回滚成功。

MVP完成的判断：一批真实公开样本可追溯、可审核、能带许可与版本导给Easel草稿，撤回与修订闭环通过，成本可记录且有用户批准的实际上限。仅有漂亮首页、信源列表或HTTP200不算交付完成。
